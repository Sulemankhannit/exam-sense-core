# 🧠 Exam Sense AI (The Intuition Engine)

> **"Don't memorize. Understand."**

## ❤️ The Core Philosophy (The "Why")

Most AI tutors fail because they are trained on textbooks. They try to teach you definitions before you understand the concept. **Exam Sense AI** is different because it is built on the **3Blue1Brown philosophy** (created by Grant Sanderson).

### What is the "Base" of 3Blue1Brown?

* **Math is a Sense, Not a Language:** Standard education treats math like a language of symbols ($dx$, $\int$, $\Sigma$). 3Blue1Brown treats math like a sense (sight, touch). It believes you should visualize the "moving machinery" of a concept before you ever write down a formula.
* **Discovery over Definition:** Instead of stating a rule, 3Blue1Brown presents a paradox that forces you to invent the rule yourself.

| Context | Approach |
| :--- | :--- |
| **Textbook** | "Here is the formula for a limit." |
| **3b1b (and this AI)** | "How can a car have a speed at a single instant if time doesn't pass? That's a contradiction. We need to invent a new tool to solve this." |

### Manim (The Engine Behind the Data)
The intuition in this database wasn't drawn by hand; it was generated by code. Grant Sanderson built **Manim** (Mathematical Animation Engine), a Python library that generates precise mathematical animations. This means the data in this system is mathematically rigorous by design.

## 🏗 Architecture

**Exam Sense AI** is a **Retrieval-Augmented Generation (RAG)** system designed to teach complex physics and mathematics concepts through intuition and storytelling, rather than rote memorization.

It uses a semantic search engine to retrieve "atomic intuition cards" (based on the work of 3Blue1Brown) and an LLM (Google Gemini) to synthesize those facts into a Socratic dialogue.

This project is not a simple wrapper. It implements a full **ETL (Extract, Transform, Load) + RAG** pipeline.

### 🛠 Tech Stack

* **Language:** Python 3.10+
* **LLM:** Google Gemini API (`google-generativeai`)
* **Vector Database:** ChromaDB
* **Embeddings:** Sentence-Transformers (HuggingFace)
* **Frontend:** Streamlit

## 🚀 Installation & Setup

### 1. Clone the Repository
```bash
git clone [https://github.com/Sulemankhannit/exam-sense-core.git](https://github.com/Sulemankhannit/exam-sense-core.git)
cd exam-sense-core

2. Install Dependencies
pip install -r requirements.txt

3. Configure Secrets
Create a .streamlit folder and a secrets.toml file to store your API key securely:

File: .streamlit/secrets.toml
GEMINI_API_KEY = "YOUR_GOOGLE_API_KEY_HERE"
4. Build the Brain (Optional)
If you want to regenerate the database from scratch, run the ETL pipeline:
# Extract raw data
python miner.py

# Process and Chunk data
python refinery.py

# Create Vector Embeddings
python engine.py
5. Run the App
streamlit run app.py

📂 Project Structure
data/: Stores the raw text and the ChromaDB vector indices.

miner.py: The "Extraction" layer of the ETL pipeline.

refinery.py: The "Transformation" layer (Cleaning & Chunking).

engine.py: The logic for embedding and indexing the data.

app.py: The main application logic and User Interface.
